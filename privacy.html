Política de privacidade

Esta ferramenta é usada por uma única pessoa, o dono desta conta do GitHub, para acessar a própria conta do Gmail.

  • Dados acessados: mensagens e anexos do Gmail do próprio dono, somente leitura (gmail.readonly), além de nome e e-mail para identificar a conta.
  • Onde ficam: no computador do dono. O token de acesso fica em arquivo local protegido; os anexos baixados ficam em pasta local.
  • Compartilhamento: nenhum dado é vendido, publicado ou enviado a terceiros pela ferramenta.
  • Revogação: o acesso pode ser revogado a qualquer momento em myaccount.google.com/permissions.

O uso de dados obtidos das APIs do Google segue a Google API Services User Data Policy, incluindo os requisitos de uso limitado.
